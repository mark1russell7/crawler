## Why a polite crawler

Research reads the same sources again and again. A plain web fetch goes back to the site each time, and nothing stays. This crawler fetches a page one time, keeps the response, and answers the next questions from a local index. Each site sees one request at a time, from a crawler that tells its name.

<CardGrid>
  <Card title="It obeys the site" icon="approve-check">
    The crawler reads robots.txt as RFC 9309 specifies. It obeys `Retry-After`, and it stops at a challenge, a 401, a 402 or a 403. [Test a robots.txt](tools/robots-txt-tester/).
  </Card>
  <Card title="It reads the cheap way" icon="document">
    The crawler reads the JSON-LD, the visible text and the links with no browser. It opens a headless browser only for a page that needs JavaScript. [See what it reads](tools/page-reader/).
  </Card>
  <Card title="It answers from the disk" icon="seti:db">
    Each response goes into a capture log. A full-text index finds passages, and a local model can also find them by meaning. A quote check finds the exact text to cite. [How hybrid search ranks](guide/search/).
  </Card>
  <Card title="It tells its name" icon="information">
    Each request sends the User-Agent `PoliteCrawler` with a link to [a page for site owners](bot/). A site can refuse it by name, and the crawler obeys.
  </Card>
  <Card title="It reads hours and prices" icon="puzzle">
    The recipes read the opening hours of a venue and the price of a product, with the source of each value. `polite-crawler venue` and `polite-crawler product` start them. [Write a recipe](guide/recipes/) for a source of your own.
  </Card>
  <Card title="It watches pages" icon="clock">
    The daemon checks a watch list on a schedule. A change needs a second check, and then the daemon writes it as one JSON line. [The daemon, tick by tick](guide/daemon/).
  </Card>
</CardGrid>

## For AI agents

One command gives Claude nine tools. The tools fetch pages politely, search the store, read a range of a document, check a quote and check the field values of a page. Two more tools list the pages of a site and crawl a few of them. The last two compare two versions of a page and list the watched pages.

```sh
claude mcp add polite-crawler -- npx -y polite-crawler mcp
```

<AgentReplay client:visible />

The same server works in Claude Desktop, Cursor, VS Code and each MCP client. [Set up the MCP server](guide/mcp/).

## As a library

```ts
import { openCrawler } from "polite-crawler";

const crawler = openCrawler({ dir: "./crawl" });
const page = await crawler.fetch("https://en.wikipedia.org/wiki/Web_crawler");

crawler.find("robots exclusion"); // ranked passages, with no request
crawler.verify(page.doc!, "robots.txt protocol"); // the exact span and the capture to cite
```
