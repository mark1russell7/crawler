---
title: Command line
description: The polite-crawler command line - fetch, find, read, verify, reindex and mcp, with each option.
---

```sh
npx polite-crawler <command> [options]
```

## Commands

| Command | What it does |
| --- | --- |
| `fetch <url...>` | It fetches the pages into the store. robots.txt applies. |
| `find <query>` | It searches the stored pages. It sends no request. |
| `read <doc>` | It prints a range of a stored document. |
| `verify <doc> <quote>` | It finds a quote in a stored document. |
| `reindex` | It builds the search index again from the capture log. |
| `mcp` | It starts the MCP server on the standard input and output. |

## Options

These options apply to each command:

| Option | Default | What it does |
| --- | --- | --- |
| `--dir <path>` | `$POLITE_CRAWLER_DIR`, or `~/.polite-crawler` | The store. A path that starts with `~` is in your home folder, and a relative path starts at the working folder. |
| `--contact <text>` | `$POLITE_CRAWLER_CONTACT` | An email (in `From` and the `User-Agent`) or a URL (in the `User-Agent` only). |
| `--allow-private` | `$POLITE_CRAWLER_ALLOW_PRIVATE=1` | Fetch loopback, private and link-local addresses too. By default, the crawler refuses them. |
| `--no-browser` | | Do not open the headless browser. |
| `--json` | | Print JSON. |
| `-v`, `--version` | | Print the version and stop. |
| `-h`, `--help` | | Print the commands and the options, and stop. |

These options apply to one command. The command line is wrong when another command gets them.

| Command | Option | Default | What it does |
| --- | --- | --- | --- |
| `fetch` | `--render <mode>` | `auto` | `auto`, `never` or `always`. |
| `fetch` | `--max-age <age>` | `24h` | A stored copy younger than this age answers with no request. `0` fetches the page again. |
| `find` | `--limit <n>` | `10` | The number of results. |
| `find` | `--kind <kind>` | all | Only this kind of document, for example `page` or `pdf`. |
| `read` | `--from <n>` | `0` | The position where the range starts. |
| `read` | `--length <n>` | `4000` | The number of characters to print. |
| `read` | `--user-provided` | | Read a page that asked not to be AI input. Use it only for a URL that you gave yourself. The crawler records each such read. |
| `mcp` | `--allow-user-provided` | `$POLITE_CRAWLER_ALLOW_USER_PROVIDED=1` | Let `user_provided` work when the MCP client cannot ask the user. |

## Exit codes

| Code | Meaning |
| --- | --- |
| `0` | The command did its work. |
| `1` | The command did not do its work: a page that the crawler did not fetch, no search result, a quote that is not in the document, a document that is not stored or that is held back, or an error. |
| `2` | The command line is wrong. The command opens no store. |

## Examples

```sh
# two sites at the same time, one request at a time to each
npx polite-crawler fetch https://example.com/ https://en.wikipedia.org/wiki/Web_crawler

# JSON for a program
npx polite-crawler find "opening hours" --limit 5 --json

# a store for one project
npx polite-crawler fetch https://example.com/ --dir ./research

# a script that stops when a quote is not in the page
npx polite-crawler verify "url:https://example.com/" "for use in documentation examples" || exit 1
```
